# CSS Loader
Dynamically loads CSS files from storage and reloads alongside Steam UI.

## Downloads

Download packaged updates from [this fork's GitHub Releases](https://github.com/beallio/SDH-CssLoader/releases/latest).

- **Decky Loader:** Download `SDH-CssLoader-<version>.zip` and install it with Decky Loader's local file installer. Do not use GitHub's source-code ZIP.
- **Windows:** Download `CssLoader-Standalone.exe`, or choose `CssLoader-Standalone-Headless.exe` to hide the console window.
